# Opex Menu — Interactive QR Code Digital Restaurant Menu 🍽️📱

**Opex Menu** is a lightweight, responsive, and mobile-first digital menu web application built for modern restaurants and cafes. Designed to be accessed instantly via QR code scans, it allows customers to browse food categories, search for dishes in real time, view detailed item descriptions, and interactively rate dishes directly from their phones.

---

## 🌟 Key Features

* **Mobile-First UX:** Tailored specifically for smartphone screens (`max-w-md` layout) with smooth touch interactions and floating category tabs.
* **Instant Category Filtering:** Effortlessly switch between dish categories (*Burgers, Pizza, Salads, Drinks, Desserts*) with zero page reloads.
* **Interactive Rating System:** Allows customers to give star ratings (1 to 5 stars) to dishes after experiencing their meal.
* **Real-Time Live Search:** Filter dishes instantaneously by typing keywords into the interactive search bar.
* **Responsive Food Cards:** High-quality food visuals, badge highlights (*Best Seller, New*), detailed ingredient descriptions, and clean pricing layouts.
* **QR Code Ready:** Optimized for quick loading upon scanning tabletop QR codes without requiring app installations or complex logins.

---

## 🛠️ Built With

* **HTML5:** Clean, semantic structure for web accessibility.
* **Tailwind CSS:** Modern utility-first CSS framework for fast, mobile-first styling and glassmorphism UI touches.
* **JavaScript (Vanilla ES6+):** Dynamic rendering, array filtering methods, DOM manipulation, and interactive state management.
